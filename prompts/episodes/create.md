
# 새 에피소드 생성

## 목적
지정된 번호의 에피소드를 새로 생성한다.

## 절차
1. AGENTS.md와 harness/META_HARNESS.md를 읽는다.
2. 지정된 에피소드 번호의 기존 폴더를 확인한다.
3. 아래 명령을 실행한다.

   python3 tools/new_episode.py {번호}

4. 생성된 폴더와 episode.yaml의 ID를 검증한다.
5. 기존 파일을 덮어쓰거나 삭제하지 않는다.

## 결과 보고
- 생성된 에피소드 ID
- 생성 경로
- 파일 목록
- 검증 결과

작업 결과를 한국어로 보고한다.
